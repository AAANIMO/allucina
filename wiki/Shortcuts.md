# Shortcuts

| Key | Action |
|---|---|
| `E` | Edit ↔ Projection |
| `I` | Invert colors (whole screen) |
| `Shift+I` | Auto-invert on/off |
| `F` | Fullscreen |
| `⌫` / `Del` | Delete selection |
| `⌘/Ctrl + D` | Duplicate |
| Arrows | Move (with `Shift` = step 10) |
| `[` / `]` | Back / forward one level |
| `Shift+[` / `Shift+]` | Send to back / bring to front |
| `Space` + drag | Pan |
| `Esc` | Deselect / cancel vertices |
